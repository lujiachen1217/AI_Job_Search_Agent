# AI Job Search Agent

## Project Goal

Build an AI-powered job search assistant that can:

- Parse and analyze a resume
- Fetch normalized jobs from Greenhouse, Lever, and Ashby
- Apply title, seniority, location, and experience hard filters
- Rank candidates by skill match and AI semantic match
- Analyze US employment visa sponsorship evidence
- Produce an LLM job decision and cover letter
- Export the final results to Excel

## Tech Stack

- Python
- OpenAI API
- Pandas
- Streamlit (Later)
- Git & GitHub
